Join this heimdall fleet

Run the model on your phone's real GPU with a native app — more reliable than a browser, and it works on your Wi-Fi or over Tailscale across networks.

1. Install the app

iOS
OnDevice LLM
Android
LLM AI Server with llama.cpp Ollama Local AI — Phone IDE
Open this page on your phone to see the right app.

2. Start its server

In the app, download a model and start the local API server. It shows an address like http://100.64.0.7:8000 (Tailscale) or http://192.168.1.50:8080 (Wi-Fi). Keep the app open — phones pause a background server.

3. Link it on the computer

On the computer running heimdall, open http://localhost:8790/link, paste the address the app shows, and tap Test & add. The phone is now a host behind your fleet.
